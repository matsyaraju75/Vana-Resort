Project Vision

Executive Summary & Core Objectives

Connecting Araku Valley eco-tourism with a frictionless digital guest experience.

INDUSTRY NEED

The Challenge

Traditional hill resort websites suffer from outdated information, complex third-party booking commissions, lack of authentic room photos, and network downtime.

  • High OTA commissions (15–25%)
  • Misleading generic photos & room sizes
  • Lack of curated regional attraction guides
  • No direct WhatsApp concierge interaction
OUR APPROACH

The Solution

A bespoke web platform for Vana Resort Araku combining verified property details, room-only galleries, an offline-resilient booking engine, and direct WhatsApp concierge.

  • 100% direct bookings with zero commissions
  • Strictly verified room & bathroom photos
  • Comprehensive guide for 11 Araku spots
  • Offline-resilient architecture with fallback

A seamless, full-featured web app that gives travelers instant clarity, easy booking inquiries, and empowers resort management with a full operational admin dashboard.

System Design

Technical Architecture & Engineering Stack

Engineered for extreme performance, offline fault-tolerance, and modern developer ergonomics.

CLIENT LAYER

Frontend Architecture

React 19 single-page application built with strict TypeScript and Vite 8 for instant HMR feedback.

  • React 19: Modern hooks, Context API state management
  • TypeScript: End-to-end interface contracts and types
  • Tailwind CSS: Curated resort tokens and glassmorphism
  • Lucide React: Lightweight SVG icon system
RESILIENCE LAYER

Offline-First Engine

Ensures the guest booking and admin experience never fails even when the PHP backend is unreachable.

  • Transparent Fallback: Automatically saves to localStorage
  • Dynamic Price Engine: Real-time night & tariff calculation
  • Instant VR-XXXXXX Ref: Immediate tracking codes
  • WhatsApp Deep-Link: Pre-filled direct booking payload
SERVICES LAYER

Backend & Database

Production-grade PHP 8.2 REST API with structured MySQL 8 database schema and session auth.

  • PHP 8.2 REST API: Modular controllers for rooms, bookings
  • MySQL 8 Schema: Relational seed tables & foreign keys
  • Session Auth: Secure cookie transmission for admin
  • Google Hotels XML: Automated syndication feeds

Reservation Workflow

Booking Engine & Offline Resilience

Frictionless booking experience with dynamic tariff calculation and direct WhatsApp hand-off.

01

Dates & Room Selection

Guest selects check-in, check-out dates, guest party size, and room category.

✔ Dynamic night counter & instant estimated total based on sample tariffs.
02

Client Validation

Ensures 10-digit mobile number, valid forward dates, and correct party allocations.

✔ Zero page reload, instant validation errors, accessible form controls.
03

Offline Resilience

Attempts backend PHP API. If offline, seamlessly persists booking to browser localStorage.

✔ Generates unique VR-XXXXXX reference with zero annoying server errors!
04

WhatsApp Hand-off

Success confirmation card displays stay breakdown and direct WhatsApp concierge button.

✔ Pre-formatted message: ID, Room, Dates, Nights, Tariff sent to +91 90141 15175.
